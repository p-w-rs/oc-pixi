# [pixi](../../index.md) [workspace](../index.md) [platform](index.md) list

List every workspace platform with full detail, preceded by the auto-detected host as a separate entry

## Usage
```
pixi workspace platform list [OPTIONS]
```

## Options
- <a id="arg---json" href="#arg---json">`--json`</a>
:  Emit machine-readable JSON instead of the human view
