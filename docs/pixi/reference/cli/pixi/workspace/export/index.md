# [pixi](../../index.md) [workspace](../index.md) export

Commands to export workspaces to other formats

## Usage
```
pixi workspace export <COMMAND>
```

## Subcommands
| Command | Description |
|---------|-------------|
| [`conda-explicit-spec`](conda-explicit-spec.md) | Export workspace environment to a conda explicit specification file |
| [`conda-environment`](conda-environment.md) | Export workspace environment to a conda environment.yaml file |
