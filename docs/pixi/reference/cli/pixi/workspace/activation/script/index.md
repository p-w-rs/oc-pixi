# [pixi](../../../index.md) [workspace](../../index.md) [activation](../index.md) script

Commands to manage the `activation.scripts` list

## Usage
```
pixi workspace activation script <COMMAND>
```

## Subcommands
| Command | Description |
|---------|-------------|
| [`add`](add.md) | Add activation script(s) to the end of `activation.scripts` |
| [`prepend`](prepend.md) | Add activation script(s) to the front of `activation.scripts`, moving them there when they are already present |
| [`remove`](remove.md) | Remove activation script(s) from `activation.scripts` |
| [`list`](list.md) | List the activation scripts in the manifest |
