# [pixi](../../index.md) [global](../index.md) shortcut

Interact with the shortcuts on your machine

## Usage
```
pixi global shortcut <COMMAND>
```

## Subcommands
| Command | Description |
|---------|-------------|
| [`add`](add.md) | Add a shortcut from an environment to your machine. |
| [`remove`](remove.md) | Remove shortcuts from your machine |
